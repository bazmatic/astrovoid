# Rules Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a headless experiment loop that scores the rules hunter on seeded levels and refines its rules by measured experiment.

**Architecture:** `RuleParams` makes the rules' numbers explicit and injectable. A harness runs the real `Game` headless with a fake clock and a synchronous pilot, one episode per (level, seed). A score and a paired-bootstrap test compare candidates; a runner spreads episodes over CPU cores; a search proposes numeric changes; a notebook records every experiment.

**Tech Stack:** Python 3.10 (`venv/bin/python`), pygame under the dummy SDL driver, numpy, multiprocessing (spawn), pytest. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-11-rules-lab-design.md`

## Global Constraints

- Run everything with `venv/bin/python`; tests as `venv/bin/python -m pytest <path> -q`.
- `Game`, `HunterController`, `HunterShip` and `PilotWorker` are not modified. Changes to existing code are limited to: `hunter/pilot_sensors.py` (take a `params` argument), `hunter/jev_pilot.py` (`JevPilot` takes `params`), `hunter/rules_pilot.py` (take `params`).
- With default `RuleParams`, behaviour is identical to today: the existing hunter tests (`tests/test_hunter_*.py`, `tests/test_rules_pilot.py`, `tests/test_student_*.py`) must keep passing unchanged.
- The harness runs at 1352x878 (the real play scale), hunter alone: the player is parked, hidden from the hunter, and cannot fail or finish the level. Episodes use `HunterSettings(indestructible=False)`.
- Horizon 90 simulated seconds; fake clock advances 1/60 s per frame; the pilot is called synchronously.
- Tune levels: 13, 14, 15, 17, 19, 20, 22, 25, 26, 27, 18, 30. Held-out levels: 16, 21, 23, 28, 29, 24. Seeds 0 and 1. The held-out set is never used to choose a candidate.
- An improvement requires a positive paired difference on the tune set with a 95% paired bootstrap interval that excludes zero.
- Raw results go to `.astrovoid-local/experiments/` (already gitignored via `/.astrovoid-local/`). Notebook entries go to `docs/experiments/`.
- Never touch the user's real profile file: the harness replaces `ProfileManager` with one on a temp path.
- Code style matches `hunter/`: single quotes, 4-space indent, short docstrings.
- Commit messages end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus

Failure modes the spec implies that no task would otherwise test, most likely first. Each has a test in the task that owns the code.

1. State leaking between episodes in one process (a reused `Game`, global `random`, entity ids): the same (level, seed, params) must give identical results whether it runs first or fifth. (Task 2)
2. An episode where the hunter dies in the first frames, or a level that starts with no enemies: no division by zero, a sensible `end`, and a score that is finite. (Tasks 2 and 3)
3. A params JSON with an unknown key, a wrong type or an out-of-range value: a clear error, never a silent default. (Task 1)
4. One crashing episode in a parallel batch: the error names the level, seed and params; it is never swallowed into a good-looking number. (Task 4)
5. An interrupted run leaving a half-written results file that a later run reads as complete. (Task 4)

```python
"""The numbers the rules hunter is tuned by. Defaults are the game's current values."""
from dataclasses import asdict, dataclass, fields


@dataclass(frozen=True)
class RuleParams:
    steer_band_degrees: float = 20.0  # Within this of the nose, hold no steering
    engage_standoff_cells: float = 1.5  # The distance the hunter fights from, in maze cells
    too_close_ratio: float = 0.6  # Closer than this share of the standoff is too close
    far_ratio: float = 1.15  # Further than this multiple of the standoff is far
    harmless_speed: float = 15.0  # m/s below which a wall brush is harmless
    wall_follow_cruise: float = 0.6  # Share of the wall-following cruise speed
    course_approach_fraction: float = 0.7  # Share of the speed limit a course holds at
    cruising_speed_fraction: float = 0.5  # Share of the safe speed that counts as cruising
    pulse_frames: float = 6.0  # Length of one engine pulse, in frames
    request_interval: float = 0.25  # Seconds between pilot decisions

    def to_dict(self):
        return asdict(self)

    @classmethod
    def from_dict(cls, data):
        known = {f.name for f in fields(cls)}
        values = {}
        for name, value in data.items():
            if name not in known:
                raise ValueError(f'unknown rule parameter {name!r}')
            if isinstance(value, bool) or not isinstance(value, (int, float)):
                raise ValueError(f'rule parameter {name!r} must be a number, got {value!r}')
            low, high = BOUNDS[name]
            if not low <= value <= high:
                raise ValueError(f'rule parameter {name!r}={value} is outside {low}..{high}')
            values[name] = float(value)
        return cls(**values)


DEFAULT = RuleParams()

# The ranges the search may explore, and the limits from_dict accepts.
BOUNDS = {
    'steer_band_degrees': (2.0, 60.0),
    'engage_standoff_cells': (0.5, 4.0),
    'too_close_ratio': (0.2, 0.95),
    'far_ratio': (1.0, 2.5),
    'harmless_speed': (2.0, 60.0),
    'wall_follow_cruise': (0.2, 1.2),
    'course_approach_fraction': (0.3, 1.0),
    'cruising_speed_fraction': (0.1, 0.9),
    'pulse_frames': (1.0, 20.0),
    'request_interval': (0.05, 0.5),
}
```

```python
FPS = 60
IDLE_AFTER_SECONDS = 20.0
SCREEN = (1352, 878)


@dataclass(frozen=True)
class EpisodeResult:
    level: int
    seed: int
    enemies_at_start: int
    elapsed: float
    kills: int
    wall_hits: int
    hits_taken: int
    idle_seconds: float
    died: bool
    end: str  # 'cleared', 'died' or 'horizon'


class EventCounter:
    """Turns per-frame observations into event counts."""

    def __init__(self):
        self.kills = 0
        self.wall_hits = 0
        self.hits_taken = 0
        self.idle_seconds = 0.0
        self._enemies = None
        self._in_wall = False
        self._last_kill = 0.0
        self._last_tick = None

    def enemies(self, count):
        if self._enemies is not None and count < self._enemies:
            self.kills += self._enemies - count
            self._last_kill = self._last_tick if self._last_tick is not None else 0.0
        self._enemies = count

    def wall(self, hit):
        if hit and not self._in_wall:
            self.wall_hits += 1
        self._in_wall = bool(hit)

    def hit_taken(self):
        self.hits_taken += 1

    def tick(self, now):
        """Time passes: seconds beyond IDLE_AFTER_SECONDS since the last kill are idle."""
        if self._last_tick is not None and now - self._last_kill > IDLE_AFTER_SECONDS:
            self.idle_seconds += now - self._last_tick
        self._last_tick = now


class SyncWorker:
    """The PilotWorker interface, answering at once from the rules pilot."""

    def __init__(self, params, clock):
        self.pilot = JevPilot(RulesClient(params), params)
        self.clock = clock
        self._result = None
        self.busy = False

    def submit(self, observation):
        decision = asyncio.run(self.pilot.decide(observation))
        self._result = PilotResult(observation.generation, observation.snapshot_at,
                                   self.clock(), decision)
        return True

    def poll(self):
        result, self._result = self._result, None
        return result

    def cancel(self):
        self._result = None

    def close(self):
        pass

    def join(self, timeout=0):
        pass


_game = None
_saved = {}


def _make_game():
    """One Game per process: real play scale, no sound, a throwaway profile file."""
    import pygame
    import config
    import game as game_module
    from profiles import ProfileManager
    pygame.init()
    pygame.display.set_mode(SCREEN)
    _saved.update(width=config.SCREEN_WIDTH, height=config.SCREEN_HEIGHT,
                  splash=config.SPLASH_ENABLED, sound=game_module.SoundManager,
                  profiles=game_module.ProfileManager)

                       request_interval=params.request_interval)

    def counting_wall(*args, **kwargs):
        hit = original_wall(*args, **kwargs)
        counter.wall(hit)
        return hit
    hunter.check_wall_collision = counting_wall

    original_damage = hunter.take_damage

    def counting_damage():
        lands = hunter.active and hunter.immunity_remaining <= 0
        died = original_damage()
        if lands:
            counter.hit_taken()
        return died
    hunter.take_damage = counting_damage

    start_enemies = _enemy_count(game)
    counter.enemies(start_enemies)
    end = 'horizon'
    elapsed = 0.0
    for _ in range(int(horizon * FPS)):
        now[0] += 1 / FPS
        elapsed += 1 / FPS
        game.update(1.0)
        counter.enemies(_enemy_count(game))
        counter.tick(elapsed)
        if not hunter.active:
            end = 'died'
            break
        if start_enemies and _enemy_count(game) == 0:
            end = 'cleared'
            break
    game._close_hunter()
    return EpisodeResult(level, seed, start_enemies, elapsed, counter.kills, counter.wall_hits,
                         counter.hits_taken, counter.idle_seconds, end == 'died', end)
```

```python
"""Scores hunter episodes and compares candidates with a paired bootstrap."""
from dataclasses import dataclass
import numpy as np

RATE_FLOOR_SECONDS = 20.0


@dataclass(frozen=True)
class Weights:
    wall: float = 0.5
    hit: float = 2.0
    idle: float = 5.0
    death: float = 10.0


def components(result):
    """Each term of the score on its own, so no gain can hide a loss."""
    minutes = max(result.elapsed, RATE_FLOOR_SECONDS) / 60.0
    idle = result.idle_seconds / result.elapsed if result.elapsed > 0 else 0.0
    return {'kills_per_min': result.kills / minutes,
            'wall_hits_per_min': result.wall_hits / minutes,
            'hits_taken_per_min': result.hits_taken / minutes,
            'idle_fraction': idle,
            'died': 1.0 if result.died else 0.0}


def score(result, weights=Weights()):
    c = components(result)
    return (c['kills_per_min'] - weights.wall * c['wall_hits_per_min']
            - weights.hit * c['hits_taken_per_min'] - weights.idle * c['idle_fraction']
            - weights.death * c['died'])


def mean_components(results, weights=Weights()):
    rows = [components(r) for r in results]
    mean = {key: float(np.mean([row[key] for row in rows])) for key in rows[0]}
    mean['score'] = float(np.mean([score(r, weights) for r in results]))
    return mean


def paired_bootstrap(base, candidate, samples=2000, seed=0):
    """(mean difference, 2.5th, 97.5th percentile) of candidate - base over paired episodes."""
    base, candidate = np.asarray(base, dtype=float), np.asarray(candidate, dtype=float)
    if base.shape != candidate.shape or base.ndim != 1 or not len(base):
        raise ValueError('base and candidate must be equal-length, non-empty score lists')
    diffs = candidate - base
    rng = np.random.default_rng(seed)
    means = rng.choice(diffs, size=(samples, len(diffs)), replace=True).mean(axis=1)
    return (float(diffs.mean()), float(np.percentile(means, 2.5)),
            float(np.percentile(means, 97.5)))


def improves(base, candidate, **kwargs):
    """True when the candidate beats the base by more than the noise (95% interval above zero)."""
    return paired_bootstrap(base, candidate, **kwargs)[1] > 0
```

```python
"""Runs seeded hunter episodes in parallel: python -m experiments.run."""
import argparse
import json
import multiprocessing
import os
import time
from dataclasses import asdict
from pathlib import Path

from experiments.harness import EpisodeResult
from experiments.score import mean_components
from hunter.rule_params import DEFAULT, RuleParams

TUNE_LEVELS = (13, 14, 15, 17, 19, 20, 22, 25, 26, 27, 18, 30)
HELDOUT_LEVELS = (16, 21, 23, 28, 29, 24)
SEEDS = (0, 1)
LEVEL_SETS = {'tune': TUNE_LEVELS, 'heldout': HELDOUT_LEVELS}
RESULTS_DIR = Path(__file__).resolve().parents[1] / '.astrovoid-local' / 'experiments'


class EpisodeError(RuntimeError):
    """An episode crashed; the message names it."""


def episode_list(level_set, seeds=SEEDS):
    return [(level, seed) for level in LEVEL_SETS[level_set] for seed in seeds]


def _use_dummy_drivers():
    os.environ['SDL_VIDEODRIVER'] = 'dummy'
    os.environ['SDL_AUDIODRIVER'] = 'dummy'


def _episode(level, seed, params, horizon):
    from experiments.harness import run_episode
    return run_episode(level, seed, params, horizon)


def _run_one(args):
    level, seed, params_dict, horizon = args
    params = RuleParams(**params_dict)
    try:
        return _episode(level, seed, params, horizon)
    except Exception as exc:
        raise EpisodeError(
            f'level {level} seed {seed} params {params_dict}: {type(exc).__name__}: {exc}') from None


def evaluate(params=DEFAULT, level_set='tune', seeds=SEEDS, horizon=90.0, workers=1):
    jobs = [(level, seed, params.to_dict(), horizon) for level, seed in episode_list(level_set, seeds)]
    if workers <= 1:
        return [_run_one(job) for job in jobs]
    context = multiprocessing.get_context('spawn')
    with context.Pool(workers, initializer=_use_dummy_drivers) as pool:
        return pool.map(_run_one, jobs, chunksize=1)


def save_results(results, path):
    """Write JSONL via a temporary file, so an interrupted run never leaves a partial file."""
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    temporary = path.with_suffix(path.suffix + '.tmp')
    try:
        with open(temporary, 'w', encoding='utf-8') as handle:
            for result in results:
                handle.write(json.dumps(asdict(result)) + '\n')
        os.replace(temporary, path)
    finally:
        if temporary.exists():
            temporary.unlink()


def load_results(path):
    with open(path, encoding='utf-8') as handle:
        return [EpisodeResult(**json.loads(line)) for line in handle if line.strip()]


def load_params(path):
    if path is None:
        return DEFAULT
    return RuleParams.from_dict(json.loads(Path(path).read_text(encoding='utf-8')))


def main(argv=None):
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument('--params')
    parser.add_argument('--set', default='tune', choices=sorted(LEVEL_SETS))
    parser.add_argument('--seeds', type=int, default=len(SEEDS))
    parser.add_argument('--horizon', type=float, default=90.0)
    parser.add_argument('--workers', type=int, default=os.cpu_count() or 1)
    parser.add_argument('--out')
    args = parser.parse_args(argv)
    _use_dummy_drivers()
    params = load_params(args.params)
    started = time.perf_counter()
    results = evaluate(params, args.set, tuple(range(args.seeds)), args.horizon, args.workers)
    out = Path(args.out) if args.out else RESULTS_DIR / f'{time.strftime("%Y%m%d-%H%M%S")}-{args.set}.jsonl'
    save_results(results, out)
    print(f'{len(results)} episodes in {time.perf_counter() - started:.0f}s -> {out}')
    for key, value in mean_components(results).items():
        print(f'  {key:20s} {value:8.3f}')


if __name__ == '__main__':
    main()
```

```python
"""Proposes numeric rule changes: random search, then one-parameter hill-climbing."""
from dataclasses import replace
import numpy as np

from experiments.score import improves, paired_bootstrap
from hunter.rule_params import BOUNDS, DEFAULT, RuleParams


def sample_params(rng, bounds=BOUNDS):
    return RuleParams(**{name: float(rng.uniform(low, high)) for name, (low, high) in bounds.items()})


class CachedEvaluator:
    """Memoises an evaluator, so the baseline and revisited candidates cost one run each."""

    def __init__(self, evaluate):
        self._evaluate = evaluate
        self._cache = {}
        self.calls = 0

    def __call__(self, params, fidelity):
        key = (params, fidelity)
        if key not in self._cache:
            self.calls += 1
            self._cache[key] = list(self._evaluate(params, fidelity))
        return self._cache[key]


def _mean(evaluate, params, fidelity):
    return float(np.mean(evaluate(params, fidelity)))


def random_search(evaluate, baseline=DEFAULT, n=40, keep=4, seed=0):
    """The best `keep` of `n` random candidates: screened cheaply, ranked at full fidelity."""
    rng = np.random.default_rng(seed)
    candidates = [sample_params(rng) for _ in range(n)]
    screened = sorted(candidates, key=lambda p: _mean(evaluate, p, 'cheap'), reverse=True)[:keep]
    return sorted(screened, key=lambda p: _mean(evaluate, p, 'full'), reverse=True)


def hill_climb(evaluate, start, step=0.15, max_sweeps=3, seed=0, bounds=BOUNDS):
    """Try each parameter up and down by `step`; keep a move only if it clearly improves."""
    rng = np.random.default_rng(seed)
    current, log = start, []
    names = list(bounds)
    for _ in range(max_sweeps):
        moved = False
        for name in rng.permutation(names):
            name = str(name)
            low, high = bounds[name]
            value = getattr(current, name)
            for target in (value * (1 + step), value * (1 - step)):
                target = float(min(high, max(low, target)))
                if target == value:
                    continue
                candidate = replace(current, **{name: target})
                base_scores = evaluate(current, 'full')
                new_scores = evaluate(candidate, 'full')
                mean_diff, lo, hi = paired_bootstrap(base_scores, new_scores)
                accepted = lo > 0
                log.append({'param': name, 'from': value, 'to': target, 'accepted': accepted,
                            'mean_diff': mean_diff, 'low': lo, 'high': hi})
                if accepted:
                    current, moved = candidate, True
                    break
        if not moved:
            break
    return current, log


def optimise(evaluate, baseline=DEFAULT, n=40, keep=4, seed=0):
    """Random search for a start, then hill-climb from it if it beats the baseline."""
    base_scores = evaluate(baseline, 'full')
    start = baseline
    for candidate in random_search(evaluate, baseline, n, keep, seed):
        if improves(base_scores, evaluate(candidate, 'full')):
            start = candidate
            break
    return hill_climb(evaluate, start, seed=seed)
```

```python
"""The experiment loop's driver: python -m experiments.lab baseline|round1."""
import argparse
import json
import os
import numpy as np

from experiments import run
from experiments.score import Weights, components, improves, mean_components, paired_bootstrap, score
from experiments.search import CachedEvaluator, optimise
from hunter.rule_params import DEFAULT, RuleParams


def make_evaluator(workers, horizon_full=90.0, horizon_cheap=45.0, weights=None):
    weights = weights or Weights()

    def evaluate(params, fidelity):
        if fidelity == 'full':
            results = run.evaluate(params, 'tune', run.SEEDS, horizon_full, workers)
        elif fidelity == 'cheap':
            results = run.evaluate(params, 'tune', (0,), horizon_cheap, workers)
        else:
            raise ValueError(f'unknown fidelity {fidelity!r}')
        return [score(r, weights) for r in results]
    return CachedEvaluator(evaluate)


def baseline_weights(results):
    """Each penalty is weighted so its spread can swing the score by half the kill rate's spread."""
    rows = [components(r) for r in results]
    kill_std = float(np.std([row['kills_per_min'] for row in rows]))
    defaults = Weights()
    chosen = {}
    for field, term in (('wall', 'wall_hits_per_min'), ('hit', 'hits_taken_per_min'),
                        ('idle', 'idle_fraction'), ('death', 'died')):
        term_std = float(np.std([row[term] for row in rows]))
        chosen[field] = 0.5 * kill_std / term_std if term_std > 0 and kill_std > 0 else getattr(defaults, field)
    return Weights(**chosen)


def _report(title, results, weights):
    print(f'\n{title}')
    for key, value in mean_components(results, weights).items():
        print(f'  {key:20s} {value:8.3f}')


def baseline(workers):
    tune = run.evaluate(DEFAULT, 'tune', run.SEEDS, 90.0, workers)
    heldout = run.evaluate(DEFAULT, 'heldout', run.SEEDS, 90.0, workers)
    run.save_results(tune, run.RESULTS_DIR / 'baseline-tune.jsonl')
    run.save_results(heldout, run.RESULTS_DIR / 'baseline-heldout.jsonl')
    weights = baseline_weights(tune + heldout)
    print('proposed weights:', weights)
    _report('baseline, tune set', tune, weights)
    _report('baseline, held-out set', heldout, weights)
    rows = [components(r) for r in tune + heldout]
    print('\nspread across all baseline episodes (mean, std):')
    for key in rows[0]:
        values = [row[key] for row in rows]
        print(f'  {key:20s} {np.mean(values):8.3f} {np.std(values):8.3f}')


def round1(workers):
    weights = Weights()
    evaluator = make_evaluator(workers, weights=weights)
    best, log = optimise(evaluator)
    out = run.RESULTS_DIR / 'round1-best.json'
    out.parent.mkdir(parents=True, exist_ok=True)
    out.write_text(json.dumps(best.to_dict(), indent=2))
    print('best parameters:', best.to_dict())
    for entry in log:
        print(('  KEPT ' if entry['accepted'] else '  tried'), entry)
    base_held = [score(r, weights) for r in run.evaluate(DEFAULT, 'heldout', run.SEEDS, 90.0, workers)]
    best_held = [score(r, weights) for r in run.evaluate(best, 'heldout', run.SEEDS, 90.0, workers)]
    mean, low, high = paired_bootstrap(base_held, best_held)
    print(f'\nheld-out, best minus baseline: {mean:+.3f} (95% interval {low:+.3f} .. {high:+.3f})')
    print('held-out improvement is real' if improves(base_held, best_held) else
          'held-out shows no clear improvement')


def main(argv=None):
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument('command', choices=('baseline', 'round1'))
    parser.add_argument('--workers', type=int, default=os.cpu_count() or 1)
    args = parser.parse_args(argv)
    run._use_dummy_drivers()
    {'baseline': baseline, 'round1': round1}[args.command](args.workers)


if __name__ == '__main__':
    main()
```
